# Müşteri Alışveriş Analizi

Bu projede Python kullanılarak müşteri alışveriş verileri üzerinde istatistiksel analiz ve veri görselleştirme işlemleri gerçekleştirilmiştir.

## Kullanılan Teknolojiler
- Python
- Pandas
- NumPy
- Matplotlib

## Proje İçeriği
- Veri temizleme
- Eksik veri analizi
- Ortalama, medyan ve standart sapma hesaplamaları
- Grafiksel veri analizi
- Histogram, pie chart, scatter plot ve boxplot görselleştirmeleri

## Veri Seti
Projede müşteri yaş, şehir, sipariş tutarı ve ürün kategorileri gibi bilgiler kullanılmıştır.
